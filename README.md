# 📝 Notes App

A simple and modern desktop Notes application built with **Python** and **CustomTkinter**.

> ⚠️ **This is Version 1.0 — a functional demo, not the final release.**
>
> The app currently has some known bugs, and notes are **not permanently saved** when the application is closed. Persistent note storage and several improvements are planned for the next versions.

---

## ✨ Features

- 📝 Create notes
- 📂 Open and edit notes
- 🔍 Search through notes
- ✏️ Rename notes
- 🗑️ Delete notes
- 📅 Weekly calendar interface
- 🎬 Smooth UI animations
- 🖥️ Modern desktop interface
- ⚡ Built with Python and CustomTkinter

## 🚧 Current Status

### Version 1.0 — Demo

The application is **functional**, but it is still under development.

There are currently some known bugs and missing features.

### ⚠️ Important limitation

**Notes are not saved permanently yet.**

Any notes created during a session will be lost when the application is closed.

This is temporary.

---

## 🔜 Planned Updates

The next versions will focus on making the application more complete and reliable.

### 💾 Persistent Notes

The main upcoming feature is automatic saving.

Notes will be stored on the user's device so they can be restored when the application is opened again.

Planned behavior:

```text
Write a note
     ↓
Auto-save
     ↓
Close the app
