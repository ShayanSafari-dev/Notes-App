# 📝 Notes App

A simple and modern desktop Notes application built with **Python** and **CustomTkinter**.

> ⚠️ **This is Version 1.0 — a functional demo, not the final release.**
>
> The app currently has some known bugs, and notes are **not permanently saved** when the application is closed. Persistent note storage and several improvements are planned for the next versions.

---

## ✨ Features

- 📝 Create notes
- 📂 Open and edit notes + Automatic saving system
- 🔍 Search through notes
- ✏️ Rename notes
- 🗑️ Delete notes
- 📅 Weekly calendar interface
- 🎬 Smooth UI animations
- 🖥️ Modern desktop interface
- ⚡ Built with Python and CustomTkinter
